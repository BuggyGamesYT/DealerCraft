# DealerCraft

A blocky 3D farming and trading game by **Buggy Games YT**. Grow crops, craft goods and sell them to the villagers in the plaza. Prices change every day, so time your sales and climb the ranks to DealerCraft Tycoon.

▶ **Play in your browser:** https://buggygamesyt.github.io/dealercraft/
📱 **Android:** grab the APK from [Releases](https://github.com/BuggyGamesYT/DealerCraft/releases) (or the `releases/` folder).

## Project layout
- `web/` – the game (plain HTML + JavaScript with three.js). Open `web/index.html` from any static web server.
- `android/` – a tiny WebView wrapper that bundles `web/` into an APK. `android/build.sh` builds it with JDK 17 and Android build-tools/platform 37.
- `releases/` – signed APKs for every version.
